# UI and Design Aesthetics

## The Standard
This project is an **international multimillion church website**. All UI elements, styling, and animations must reflect a highly professional, cinematic, and premium quality.

## Guidelines
1. **Cinematic Feel**: Favor deep, rich color palettes (e.g., slate/navy backgrounds with gold/amber accents). Avoid flat, generic designs.
2. **Polished Interactions**: Use smooth, intentional animations (fade-ins, subtle scales on hover, slow zooms on background images) rather than sudden, jarring state changes.
3. **Typography**: Use high-contrast, elegant typography (e.g., 'Inter' for body, 'Outfit' for display/headings). Headings should be bold, tracking should be intentional, and text should be highly legible.
4. **Depth and Layers**: Utilize glassmorphism (backdrop-blur), subtle drop shadows, and overlapping elements to create depth.
5. **No Placeholders**: Ensure that code generated for UI components looks production-ready immediately, avoiding "MVP" or "basic" looks.
